# React Assignment — Q1 & Q2

This project implements both questions shown in the assignment image.

## Q1 — Student Profile Card
- Reusable `StudentCard` component
- Student name, course and semester passed through props
- Additional email, phone and city details
- Show Details / Hide Details button
- `useState` controls visibility

## Q2 — Text Analyzer
- Reusable `TextAnalyzer` component
- `useState` stores textarea input
- Displays entered text
- Character count and word count
- Separate `TextStats` component receives counts through props
- `useEffect` updates the document title whenever character count changes

## Run the project

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.
